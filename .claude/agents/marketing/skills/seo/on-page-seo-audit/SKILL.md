# On-page SEO audit

## Steps
1. **Intent first**: for each page, the main query and its intent (know / do / buy / local). One page = one intent.
2. **Keywords**: cluster related queries; never invent search volumes – cite the tool used or say "not measured".
3. **Per page check**: unique `<title>` (~50–60 chars, query near the start), meta description that earns the click,
   one H1, logical H2/H3, answer in the first paragraph, descriptive URL, internal links with clear anchors,
   image alt text, canonical, `hreflang` when there are several languages.
4. **Helpful content**: people-first, first-hand experience, author / company info visible (E-E-A-T signals);
   no thin or duplicated pages.
5. **Technical basics**: indexable (robots.txt, noindex), XML sitemap, HTTPS, mobile friendly, Core Web Vitals
   (ask the manager to hand it to fullstack-devops' `core-web-vitals` skill).
6. **Structured data** when it fits the page (Organization, LocalBusiness, Product, Article; FAQ only for real Q&A).
7. **Local SEO**: consistent name / address / phone across the web, Google Business Profile complete.

## Output
| Page | Query / intent | Issue | Fix | Priority |

## Pitfalls
- Keyword stuffing, one page targeting many intents, invented volumes or rankings.
