# Positioning statement

## Template (Geoffrey Moore, *Crossing the Chasm*)
> **For** (target customer) **who** (need or problem), **(brand)** is a (category) **that** (key benefit).
> **Unlike** (main alternative), **we** (key difference).

Then the **"only" test**: "(Brand) is the only (category) that (difference) for (customer) in (place / time)."
If the sentence is true for a competitor too, it is not a position yet.

## Steps
1. Write the target as a real segment, not "everyone". Alternatives include "doing nothing" and DIY.
2. List differences the client can **prove** today (facts from the brief – golden rule 6: no invented claims).
3. Draft 2–3 options with different angles (customer, benefit, category); for each: proofs, what it rules out, risks.
4. Recommend one; it becomes the input for personality, messaging and visual identity.
