# Client & Project Registry (source of truth)

The project-lead uses this table to know, for every Trello board, WHICH client and WHICH project it belongs to.
A board that is not listed here is never processed: the project-lead stops and asks.

- Add a row whenever a new client project board is created (the project-lead does it for you during onboarding).
- One board = one client project. Board name convention: `<Client> – <Project>`.
- Type: `company` (moral person) or `individual` (physical person).
- Status: `active`, `paused`, `archived`.
- Never put secrets or ID numbers here.
