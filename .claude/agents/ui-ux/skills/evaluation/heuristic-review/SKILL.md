# Heuristic review (Nielsen's 10 usability heuristics)

## Steps
1. List the 3–5 main user tasks; walk through each one screen by screen.
2. Check every screen against the 10 heuristics:
   1. Visibility of system status · 2. Match between system and the real world · 3. User control and freedom ·
   4. Consistency and standards · 5. Error prevention · 6. Recognition rather than recall ·
   7. Flexibility and efficiency of use · 8. Aesthetic and minimalist design ·
   9. Help users recognize, diagnose, and recover from errors · 10. Help and documentation
3. Rate each issue: 0 not a problem · 1 cosmetic · 2 minor · 3 major · 4 catastrophe.
4. Propose a fix per issue; group quick wins vs redesign.
5. Say it is an expert review, not user testing – for major decisions recommend testing with ~5 real users.

## Output
| Task / screen | Heuristic | Issue | Severity | Fix |
