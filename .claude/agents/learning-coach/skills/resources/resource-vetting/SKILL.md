# Resource vetting

## Steps
1. Search the web; keep only resources you could open or confirm (title, author / publisher, link, date or edition).
   Never cite a book or course you did not find.
2. Prefer: official docs, recognised publishers and universities, authors with real practice, recent editions
   for fast-moving tech.
3. Check level and prerequisites, language, cost, last update, and real reviews (no invented ratings).
4. Max 3 per need: one main resource + one alternative + one practice source. Say why each fits the owner.
5. Mark anything you could not verify as "not verified" instead of dropping it silently.

## Output
| Resource | Type | Author / publisher | Level | Cost | Language | Link | Why |
