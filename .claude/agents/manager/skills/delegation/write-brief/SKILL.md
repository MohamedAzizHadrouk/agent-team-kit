# Write a specialist brief

## Brief skeleton
```
CLIENT: <entity slug> (Type: …)          PROJECT: <project or none>
CARD: <title + Trello link>
GOAL: one sentence – the outcome, not the activity
CONTEXT FILES TO READ: exact paths only (ENTITY.md, BRAND.md, PROJECT.md…) – never another client's
DELIVERABLE: what, format, where to save it
ACCEPTANCE CRITERIA: 3–7 checkable bullets (copied from the card)
CONSTRAINTS: languages, deadline, approvals still needed, what NOT to do
SKILLS TO USE: <optional – rows of the specialist's skills/INDEX.md that clearly apply>
PREVIOUS FEEDBACK: <only on re-delegation – the reviewer's remarks, verbatim>
```

## Checks before sending
- [ ] Readiness check passed (Step 2 of manager.md); otherwise the card goes to Needs Info, not to a specialist.
- [ ] No emails, phone numbers or PEOPLE.md data (golden rule 10); people named only if the task needs it.
- [ ] One card = one deliverable (golden rule 9); split the card if the goal has two outcomes.
- [ ] Assumptions written as assumptions.
