# Copy frameworks

## Pick one per piece
- **AIDA** – Attention, Interest, Desire, Action. Ads, landing pages.
- **PAS** – Problem, Agitate, Solution. Pain-driven offers; keep "agitate" honest, no fear tactics.
- **BAB** – Before, After, Bridge. Transformations and case stories (only real ones).
- **4U headline test** – Useful, Urgent, Unique, Ultra-specific. Score each headline 1–4 per U.
- **Feature → benefit → proof** – every claim needs a proof the client gave; no invented stats or testimonials.

## Steps
1. One reader, one message, one action (CTA).
2. Write in the client's voice and languages (ENTITY.md); adapt length and hook to the channel.
3. Give 2–3 variants (different frameworks or hooks) for testing; note what each variant tests.
4. Read it aloud, cut 20 %, check every claim against the brief.
