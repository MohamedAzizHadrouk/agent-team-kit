# Name knockout check

## Goal
Remove obviously risky names early. This is a **screening, not legal clearance**: always say a trademark lawyer
must clear the final name before use. Never register a name, a domain or a handle (owner approval + spend = gate).

## Steps (per candidate)
1. **Identical / close marks** in the relevant Nice classes and markets:
   WIPO Global Brand Database (worldwide), EUIPO eSearch / TMview (EU), the national office of each market
   (e.g. INPI France, USPTO USA).
2. **Web and stores**: search engine, app stores, company registers – same or similar name in the same sector?
3. **Domains and handles**: main TLD + local ones; Instagram, TikTok, LinkedIn, YouTube, X (availability only).
4. **Language check**: meaning, pronunciation and slang in every language in ENTITY.md (and dialects listed).
5. Score: ✅ pass · ⚠️ risk (similar mark, other class, taken domain) · ❌ fail (identical mark same class, bad meaning).

## Output
| Name | Trademark (where, class) | Web / stores | Domain / handles | Languages | Verdict |

## Sources
