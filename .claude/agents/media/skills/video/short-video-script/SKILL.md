# Short vertical video script (Reels / TikTok / Shorts)

## Structure
| Time | Part | What we see | What we hear / read |
|---|---|---|---|
| 0–2 s | **Hook** | the most striking image or the result first | one short line that names the viewer's problem or promise |
| 2–20 s | **Body** | 3 beats max, one idea per shot, cut every 1–3 s | show, don't tell; on-screen text repeats the key words |
| last 3 s | **CTA** | logo / end card inside safe zones | one action (follow, comment, visit, save) |

## Steps
1. One message per video; write the hook in 3 variants for testing.
2. Format: 9:16, 1080×1920; keep text and logo inside the central safe area (platform buttons cover the bottom and
   right edges) – **check each platform's current specs on the web before final export** and note the date.
3. Burn-in subtitles or deliver an `.srt` (most people watch without sound); legible size and contrast.
4. Audio: only licensed music / sounds (or the platform's own library, used inside the platform); note licenses.
5. People: only with consent recorded in ENTITY.md (golden rule 3). No AI likeness of real people.
